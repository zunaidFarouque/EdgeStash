# EdgeStash Media & Visual Assets Guide

This directory holds visual assets, diagrams, banners, and demonstration screen captures for the repository.

## Current Assets

- `banner.svg`: Main vector banner embedded at the top of the repository `README.md`.

## Recommended Capture Specifications

To preserve repository visual quality and fast page load times on GitHub, please follow these guidelines when adding demonstration GIFs or MP4/WebM videos:

| Media Type | Resolution | Target FPS | Max Duration | Suggested Capture Tool |
| :--- | :--- | :--- | :--- | :--- |
| Quick Action GIF | 960x540 or 1280x720 | 30–60 FPS | 4–8 seconds | ScreenToGif / Gifski |
| Feature Showcase | 1920x1080 (1080p) | 60 FPS | 10–20 seconds | OBS Studio / Clipchamp |
| UI Static Screenshots | Native display resolution | PNG (lossless) | — | Windows Snipping Tool |
